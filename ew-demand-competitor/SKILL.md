# EW Demand Competitor

## Workflow

1. Select the closest materially relevant competitor first, then add up to two adjacent alternatives only when they answer a stated gap; if fewer are public, record the limited coverage instead of forcing three.
2. Inspect the hero/H1, CTA, examples, workflow, limits, pricing, FAQ, trust signals, and visible onboarding.
3. Use Similarweb or equivalent authorized data to inspect countries, search/paid/referral/social channels, landing pages, new pages, and outbound traffic. Use Ads Transparency for persistent messaging where available.
4. Use reviews to connect competitor weaknesses to a user job. Use Wayback for launch/page cadence and Wappalyzer/PubSpy only as feasibility or discovery context.
5. State the concrete gap, channel hypothesis, and smallest way to test them. Do not infer revenue or ownership from traffic, shared IDs, or a competitor's existence.

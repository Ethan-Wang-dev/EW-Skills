# 像素头像 avatar prompt

You are a top-tier avatar art director, character designer, pixel artist, and image-generation prompt director.

Create one single square 1:1 avatar image for the EW-Skills brand. Use the supplied portrait as visual reference, but transform it into a friendly fictional mascot rather than a realistic portrait.

## Input

- Subject type: person-inspired brand mascot
- Generation mode: image-based transformation
- Subject identity: the EW-Skills workshop helper, a cute AI skill-building companion
- Recognizable traits: medium-length dark hair with a lighter front streak, round glasses, calm friendly eyes, dark top, warm light skin tone
- Name or text to include: none
- Intended use: GitHub README hero image and repository avatar; must work as a small profile icon
- Aspect ratio: 1:1
- Background preference: clean warm cream background with a few subtle pixel accents
- Mood: cute, clever, welcoming, playful, capable
- Preserve: the recognizable hair silhouette, glasses, gentle expression, and dark clothing palette from the reference
- Avoid: memorial-photo feeling, solemn realism, stiff headshot, exaggerated beauty retouching, scary or grotesque features, busy scenery, large typography, watermarks, and unrelated characters

## Source Interpretation

Use the supplied image as the primary source for the face, hair, glasses, and palette. Preserve only the recognizable traits needed for a brand avatar. Do not copy the photograph literally and do not reproduce a photorealistic face. Replace the original background with a simplified avatar backdrop.

## Avatar Objective

Create a single centered mascot portrait: a cute pixel-art AI workshop assistant with an oversized expressive head, compact upper body, and a clear silhouette. The character is holding a small glowing Markdown card and has tiny floating pixel symbols suggesting GitHub, code brackets, a magnifying glass, and a skill spark. These symbols are decorative and must remain secondary to the face. The result must read clearly at thumbnail size and feel like a welcoming project mascot, not a personal memorial portrait, poster, cover, or sticker sheet.

## Likeness Policy

Preserve the reference subject's most recognizable visual traits through simplified pixel shapes, especially the hair, glasses, eye placement, and calm smile. Do not make an exact biometric or photorealistic copy.

## Style Application

Apply a cute, polished pixel-avatar visual language: crisp hard-edged pixel clusters, deliberate 32-bit/64-bit sprite-like simplification, clean stepped contours, limited warm palette, readable facial pixels, gentle highlights, and small controlled dithering. Use chunky pixels consistently across the character and props. Give the mascot a slightly oversized head, rounded cheeks, bright friendly eyes, and a small confident smile. Keep the design charming and icon-like, with enough detail to feel finished without becoming noisy.

Use a warm cream background, soft peach and lavender accent pixels, deep charcoal clothing, muted gold glasses, and a small cyan/lilac glow on the Markdown card. Keep generous negative space around the silhouette. No photorealistic shading, no smooth vector gradients, no painterly brushwork, and no anime poster treatment.

## Composition

- Primary visual center: the mascot's face and glasses
- Crop: centered bust avatar with the full hair silhouette, glasses, shoulders, and props safely inside the frame
- Safe area: keep all identifying features at least 10% away from every edge
- Background or frame: flat warm cream field with a restrained pixel halo and three or four tiny floating skill symbols
- Small-size readability: strong silhouette, high contrast around the eyes and glasses, simple shapes, no tiny text
- Optional text: no text in the image; the README supplies the brand name separately

## Color, Material, and Texture

Use a cohesive limited pixel palette: warm cream background, charcoal/navy clothing, dark brown hair with one honey-blonde highlight, muted gold glasses, peach cheeks, mint/cyan and lilac accents. Render every form with crisp pixel clusters, stepped edges, selective one-pixel highlights, and restrained dithering. The image should feel like a lovingly crafted modern game sprite with a soft, friendly brand mood.

## Negative Constraints

Avoid memorial-photo feeling, solemn or mournful expression, realistic skin pores, photographic lighting, smooth vector artwork, painterly brush texture, giant head pasted onto a body, cropped hair or glasses, cluttered background, extra people, duplicate faces, giant logos, readable words, title typography, watermarks, border frames, poster layout, cover layout, and multi-option compositions.

## Final Standard

Generate only one final 1:1 image. It must be a clear, cute, pixel-art brand avatar for EW-Skills, preserve the supplied subject's key visual traits without photorealistic copying, remain legible as a small GitHub icon, and communicate an approachable AI skill workshop assistant.

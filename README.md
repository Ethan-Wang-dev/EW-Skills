# EW-Skills

EW-Skills 是一个持续更新的 AI Agent Skill 集合，面向开发者、AI 实践者和产品构建者。

## 当前 Skill

### [EW-Repo Scout](ew-repo-scout/)

在 GitHub 上发现与 idea、Skill 或产品相似的开源项目，并比较目标用户、问题、工作流、产品差异和实现证据。

## 使用

将需要的 Skill 目录复制到 Codex 的技能目录（通常为 `~/.codex/skills/`），重新加载后即可使用。每个 Skill 的 README 说明其用途、参数和可自定义位置。

## 更新与贡献

每个 Skill 都应保持自包含，文档、脚本和测试一起更新。提交前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
